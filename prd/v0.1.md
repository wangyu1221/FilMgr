# 数据库

应用打开时检查是否已存在下列表，如果不存在，则创建表。

| id | bigint | Y | 自增 |  |

| sn | varchar(32) | Y |  |  |
| file_path | varchar(256) | Y |  | Y |
| file_name | varchar(256) | Y |  | Y |
| file_suffix | varchar(16) | Y |  |  |
| file_size | bigint | Y |  |  |
| mosaic | tiny_int | Y | 1 |  |
| resolution | int | Y | 1 |  |
