# 新增功能
* 项目内添加 设置对话框，当点击菜单项IDM_SETTING时打开该对话框
* IDM_SETTING添加两个tab标签：视频类型、播放器
* 视频类型tab内显示视频类型(g_videoExtensions定义)的checkbox，默认全部选中
* 播放器tab内添加按钮：选择，点击后打开文件选择对话框，筛选exe类型；添加IStatEditor，显示选择exe文件路径，
* IDM_SETTING添加两个按钮：确定和取消
* 点保存按钮时，将内容insert或update到setting表，以insert为例
insert into setting(setting_key, setting_value)values('extentions', '{".avi":1,".mp4":0}');
insert into setting(setting_key, setting_value)values('player_exe', 'c:\player\player.exe');
* g_videoExtensions改为从数据库获取，json里值=1为生效
* 根据已有的功能，将WindowsProject1.cpp内代码合理拆分成以功能为单位的多个源代码文件
