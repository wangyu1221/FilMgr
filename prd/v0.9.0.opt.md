# v0.9.0 优化 (v0.9.0 → v0.9.1)

## 1. monitor_dirs 数据结构变更

原格式为字符串数组 `["c:\\dir1", "c:\\dir2"]`，改为对象数组：
```json
[{"dir":"F:\\迅雷下载","include_sub":1}]
```

- `dir`: 目录路径
- `include_sub`: 是否包含子目录（1=是, 0=否）
- 兼容读取旧格式

## 2. ListView 第二列显示子目录状态

`IDD_MONITOR_DIR` 的 ListView 新增第二列，显示"含子目录"/"不含子目录"，与第一列的目录路径分开。

## 3. 移除 IDD_MONITOR_DIR 的包含子目录复选框

从监视目录对话框中移除"包含子目录"复选框，添加目录时 `include_sub` 默认写为 `1`。
