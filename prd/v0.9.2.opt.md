# v0.9.2 优化 (v0.9.2 → 当前)

## 1. 扫描异步化 + 取消支持

所有文件扫描操作显示 scanning dialog（`IDD_SCANNING`），包含：
- 当前扫描路径实时显示
- 取消按钮可中断扫描
- 工作线程异步执行，主界面不阻塞
- `ScanManager` 新增 cancel-aware 重载（`std::atomic<bool>& cancel` + `std::mutex& pathMutex`）

## 2. 取消崩溃修复

`ScanContext` 双 delete 问题修复：`WM_DESTROY` 不再 delete ctx，生命周期完全由 `ShowScanningDialog` 管理。

## 3. 实时显示当前文件路径

cancel-aware 扫描函数逐文件更新 `currentPath`（加锁保护），scanning dialog 显示当前正在处理的完整文件路径而非仅目录。

## 4. 移除 IDC_CHK_EXTRACT_SN

从 `IDD_DIR_SELECT` 移除"你懂的模式"复选框，所有扫描始终启用番号提取（`extractSn = true`）。

## 5. 重复文件修复

`ScanAndInsertFilmsInDir` 中去重 SQL 的 `file_path` 转义单引号，避免路径含 `'` 时查询语法错误导致误判新增。

## 6. Set 去重优化

扫描前将全量 `file_path` 加载到 `unordered_set<string>`，扫描时 O(1) 查重替代逐文件 SQL 查询，新插入路径同步加入 set。

## 7. 移除 scanning dialog 的"已发现"计数

从 `IDD_SCANNING` 移除 `IDC_SCAN_FOUND_COUNT` 控件及相关更新逻辑。

## 8. IDD_EDIT_FILM 新增 AD 编辑框

- 新增 `IDC_EDIT_AD` 只读编辑框，展示与 `duration` 相同的 HH:MM:SS 格式
- SELECT / UPDATE 增加 `ad` 字段

## 9. IDC_EDIT_AD 改为可编辑

- 移除 `ES_READONLY`
- 保存时解析 HH:MM:SS / MM:SS / 纯数字格式
- 空值 → `ad = NULL`
