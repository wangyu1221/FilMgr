# 添加新功能
## 设置对话框的播放器tab
* 添加一个ComboBox，文本为：特殊选项，选项为两个：PotPlayer和其他
* 如果选项选中PotPlayer，页面显示一个checkBox：跳过广告开始播放，其他选项则没有
* 点确定，该tab页所有内容保存于setting表，setting_key=player_config, setting_value为json格式如下：
player_type为新增combobox选项值，
player_exe_path为原原player_exe路径
player_config为combobo选择不同选项后的配置值，其下每个key值和player_type值一致
{
  "player_type": "potplayer",
  "player_exe_path": "e:\\player.exe",
  "player_config": {
    "potplayer": {
      "jumpAd": true
    }
  }
}

## ListView
* 双击操作和右键菜单打开操作一致
* 如果当前选中为PotPlayer，且jumpAd为true，则在使用player_exe_path打开播放器时增加参数 /seek=123，其中123为movie表对应记录的ad字段值，ad为null则seek=0
